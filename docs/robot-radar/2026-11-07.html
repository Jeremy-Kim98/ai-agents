11월 7일 토요일

이번 주는 모델 발표보다 도구 쪽 소식이 중심이었다. LeRobot v0.7.0이 원격 추론과 데이터 스트리밍을 넣었고, MuJoCo 4.0이 병렬 시뮬레이션 API를 내놓았으며, ROS 2 쪽에서는 Intrinsic Core가 공개됐다.

꼭 볼 것

LeRobot v0.7.0: 상호작용형 롤아웃, 원격 정책 서버, 데이터 스트리밍

오픈소스 / Hugging Face Blog (릴리스 날짜는 PyPI 기준) / 2026-11-05

v0.7.0은 실행 중인 로봇의 서브태스크를 바꾸거나 질문을 던지고 새 목표를 줄 수 있는 언어 기반 인터랙티브 롤아웃을 도입했다. 데이터셋을 다운로드 없이 Hub, Storage Bucket, LanceDB에서 바로 학습에 쓸 수 있고, Unitree G1에는 NVIDIA SONIC 전신 제어기가 붙었으며, 모든 시뮬레이터가 코어 하나로 돌아간다고 한다.

데이터 규모(Hub에 약 300TB)와 추론 구조(원격 GPU 정책 서버)를 모두 손봐서, 시연 데이터 수집부터 정책 배포까지를 한 오픈소스 스택으로 이을 수 있게 됐다.

내 연구에 적용하면
시연 데이터 수집·배포에 직접 쓸 수 있다. 수집한 시연을 LeRobot 포맷으로 두고 스트리밍 학습을 하면 저장 부담이 줄고, lerobot-policy-server로 엣지 로봇과 GPU 서버를 분리해 시뮬레이션과 실기 정책을 같은 방식으로 평가할 수 있다. 롤아웃 중 사람이 서브태스크를 바꿔 주는 기능은 '어디서 사람이 개입해야 하는가'를 로깅하는 실험에도 쓸 만하다.
“Policies can now run on a remote GPU with lerobot-policy-server”원문에서 같은 문구를 자동으로 확인했습니다

MuJoCo 4.0.0 릴리스: 배치 API, 새 적분기, Bazel 빌드

시뮬레이션 / GitHub (google-deepmind/mujoco Releases) / 2026-11-06

mujoco.batch는 한 모델의 시뮬레이션 여러 개를 자체 스레드 풀에서 돌리며, 스레드 수와 상관없이 결과가 일반 루프와 비트 단위로 같다고 한다. 이 밖에 암시적 감쇠·강성을 함께 푸는 discrete 적분기, 컴파일 시 프레임 스케일 속성, Bazel 빌드 지원이 들어갔고, 릴리스 후 mujoco/mujoco-core/mujoco-studio 분리 패키지와 OpenUSD 휠 문서도 올라왔다.

스레드 수와 무관하게 결과가 재현되는 병렬 롤아웃은 CPU 기반 대규모 정책 평가와 데이터 생성에서 재현성 문제를 줄여 준다.

내 연구에 적용하면
가상환경 구축과 과제 학습에 쓸 수 있다. 접촉이 많은 조작 과제로 '로봇이 스스로 학습 가능한가'를 가르는 사전 실험을 돌릴 때 batch API로 시드별 대량 롤아웃을 만들 수 있다. 다만 GPU 시뮬레이터(Isaac Lab, Genesis)와의 속도 비교는 확인하지 못했으니 직접 벤치마크가 필요하다.

Intrinsic Core 공개: ROS 호환 오픈소스 실시간 제어·모션 플래닝

오픈소스 / Open Robotics Discourse (ROS News for the Week of November 2nd, 2026) / 2026-11-02

ROS 커뮤니티 주간 뉴스와 ROS General 게시판에 Intrinsic Core 공개 공지가 올라왔다(게시 11/2). 제목 외의 본문 세부 사항은 확인하지 못했다.

ROS 2 생태계에 오픈소스 실시간 제어·모션 플래닝 스택이 들어오면 시뮬레이션에서 실기까지 같은 제어 계층을 쓸 선택지가 넓어진다.

내 연구에 적용하면
배포·추론 단계에서 검토할 가치가 있다. 학습한 정책을 실기에 올릴 때 하위 제어·플래닝 계층의 후보로 볼 수 있지만, 지원 로봇이나 라이선스는 원 공지에서 직접 확인해야 한다.
“Intrinsic Core released: Open-source, ROS-compatible real-time control, motion planning and more”원문에서 같은 문구를 자동으로 확인했습니다

Jetson Thor에서 TensorRT 11.2.1은 미지원: Ultralytics YOLO26 배포 가이드 주의점

엣지AI / Ultralytics Docs / 2026-11-02

Ultralytics의 YOLO26 Jetson 가이드는 TensorRT 11.2.1이 Thor를 포함한 JetPack을 지원하지 않는다고 적고 있다. Jetson 내보내기에는 JetPack 버전에 맞는 TensorRT 10.x 런타임을 쓰는 네이티브 설치를 권한다. 뉴스가 아니라 문서 페이지이고, 날짜는 검색 결과의 '5일 전' 표기로 추정했다.

TensorRT 최신 버전과 Jetson 지원 사이에 틈이 있어, 엣지 배포 파이프라인의 버전 고정이 실질적인 문제임을 보여 준다.

내 연구에 적용하면
배포·추론 단계의 체크리스트로 쓸 수 있다. Jetson Thor/Orin에서 검출기(YOLO26 등)를 TensorRT로 내보낼 때 JetPack별 TensorRT 버전을 먼저 고정해야 한다.
