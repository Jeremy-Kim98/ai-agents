CoRL 2026 총정리: 로봇 AI 스택이 '계획자'와 '실행자'로 갈라진다

로봇모델 / Core Matter (CoRL 2026 Recap) / 2026-11-13

CoRL 2026 요약 뉴스레터가 월드 액션 모델(WAM)이 올해 System 1(저수준 실행) 영역으로 들어왔다고 정리했다. VLA는 이미지와 지시로 다음 모터 명령을 내고, WAM은 비디오 생성 모델에서 출발해 향후 몇 초의 영상과 모터 명령을 함께 예측한다고 설명한다.

상위 추론(VLM 계획)과 하위 실행(WAM/VLA)을 분리하는 구조가 업계 표준 틀로 자리 잡는 흐름을 보여준다.

내 연구에 적용하면
사람/로봇 역할 분담 설계에서 상위 계획은 모델에 맡기고, 시연 데이터는 하위 실행 정책(System 1) 학습용 접촉·조작 구간에 집중 수집하는 구조를 검토할 수 있다.
“World action models moved into System 1 this year”원문에서 같은 문구를 자동으로 확인했습니다

Noitom, 손-물체 조작 모캡 데이터셋 HiPHI-Hand 공개 예정 (NVIDIA EgoHand 학습용)

로봇모델 / GlobeNewswire (Noitom Robotics) / 2026-11-09

Noitom Robotics가 NVIDIA EgoHand 학습에 쓴 11시간 분량의 정밀 손 모션캡처 데이터 HiPHI-Hand를 Hugging Face에 공개한다고 발표했다. 광학 모캡과 동기화된 1인칭 영상으로 구성되며, EgoHand는 단일 1인칭 카메라에서 3D 손 자세와 형상을 복원한다.

로봇 없이 사람 손만으로 모은 시연·손 자세 데이터의 정답(ground truth) 품질을 끌어올리는 공개 자원이다.

내 연구에 적용하면
VR·원격조작 대신 사람 손 영상으로 시연을 모으는 경로를 검토할 때, 손 자세 추정기 학습과 검증용 기준 데이터로 쓸 수 있다. 발표일이 11월 9일이라 이번 기간 경계에 있고, 공개 예정이라 실제 배포 여부는 확인이 필요하다.

GENTO 21자유도 로봇 손과 CoRL 현장 원격조작 데모, GR00T 2 시연의 외골격 손 데이터 전이

로봇모델 / Gizmodo / 2026-11-12

GENTO가 CoRL 2026에서 21자유도 손을 공개했고, 방문객 동작을 로봇이 실시간으로 따라 하는 원격조작 데모를 진행했다. NVIDIA의 GR00T 2 시연에서는 웨어러블 외골격으로 기록한 사람 손 동작을 양손 로봇에 전이해 과제를 수행했다고 한다.

고자유도 손으로 갈수록 원격조작·외골격 기반 시연이 필수 데이터 수집 수단이 된다는 점을 보여주는 현장 사례다.

내 연구에 적용하면
손 자유도가 높은 조작 과제는 시뮬레이션 강화학습만으로 풀기 어려우므로 시연이 필요한 과제군으로 분류하고, 외골격 기반 수집 방식을 데이터 수집 후보에 추가할 수 있다. 기사 게재일은 '2일 전' 표기로 추정했다.

GR00T 2는 백서만 공개, 실제로 돌려볼 수 있는 공개 가중치는 GR00T N1.7 GA

로봇모델 / RoboCloud 블로그 (2차 출처) / 2026-11-10

한 분석 사이트는 GR00T 2 백서에 가중치·라이선스·출시일이 없어 지금 실행할 수 있는 모델은 N1.7이라고 정리했다. NVIDIA GitHub의 Isaac-GR00T 저장소는 N1.7이 GA(정식) 릴리스이며 VLM 백본을 Cosmos-Reason2-2B로 바꿨다고 밝힌다. GR00T 2 가중치 미공개는 2차 출처 주장이므로 NVIDIA 공식 확인이 필요하다.

발표와 재현 가능한 공개 모델 사이의 간극을 구분해야 연구 계획에 반영할 수 있다.
