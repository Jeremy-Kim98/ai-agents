Thinking Machines, Inkling 2 Small 가중치 Hugging Face 공개

오픈소스 / Thinking Machines Lab / 2026-11-12

Thinking Machines Lab이 594B 파라미터 모델 Inkling 2 Small의 가중치를 11월 12일 Apache 2.0 라이선스로 풀었다. 일주일간의 호스팅 전용 기간이 끝났고, 중국 밖 오픈웨이트 모델 중 최상위권으로 평가된다.

llama.cpp·ggml, v1.0.0 안정 릴리스

오픈소스 / TBreak / 2026-11-13

ggml-org가 11월 13일 llama.cpp와 ggml을 v1.0.0으로 냈다. 공개 C API·ABI가 깨질 때는 메이저 버전을 올리는 방식으로 바뀌었고, 폐기된 함수 35개가 제거됐다.

로컬 추론 스택을 얹어 쓰는 도구들이 API 변경을 예측할 수 있게 됐다. 다만 이번 릴리스는 breaking change를 포함한다.

“Breaking changes to the public C API or ABI will now come with a major-version bump.”원문에서 같은 문구를 자동으로 확인했습니다

LMSYS, NVIDIA·AMD·Google·Meta 등과 SGLang 컨소시엄 출범

오픈소스 / LMSYS Org / 2026-11-12

LMSYS Org가 11월 12일 SGLang 컨소시엄을 발족했다. 창립 멤버는 NVIDIA, AMD, Intel, Google, Meta, Cloudflare, Modal, RadixArk 8곳이다.
